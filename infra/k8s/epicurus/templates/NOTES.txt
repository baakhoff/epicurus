2. THE UNSEAL KEY — BACK IT UP

   The bootstrap job created the Secret "{{ .Values.openbao.bootstrap.secretName }}" holding the
   OpenBao unseal key, the root token and the app token. It is created through the
   Kubernetes API, NOT by Helm, so `helm uninstall` leaves it alone — but nothing
   else protects it, and without the unseal key everything on the OpenBao volume is
   unreachable. Save it somewhere outside the cluster now:

     kubectl -n {{ .Release.Namespace }} get secret {{ .Values.openbao.bootstrap.secretName }} \
       -o jsonpath='{.data.unseal-key}' | base64 -d

   A restarted OpenBao pod comes back sealed; the openbao-unseal deployment
   submits the key again on its own.
{{- end }}
