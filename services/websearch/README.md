# epicurus-websearch

Web-search and link-reading module for the epicurus platform.  Gives the agent free, private
web search backed by a self-hosted [SearXNG](https://docs.searxng.org/) instance — no
external API keys or accounts required — plus `link_ingest`, which reads one
operator-supplied link (article, image, or public video) under an SSRF guard and returns its
substance.

See the full documentation page at **[docs/services/websearch.md](../../docs/services/websearch.md)**.
